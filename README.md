# Odin Recipes

Welcome to **Odin Recipes**, my very first project completed as part of [The Odin Project](https://www.theodinproject.com/) Foundations course! This project demonstrates foundational HTML knowledge by building a basic, multi-page recipe website from scratch.

---

## 🛠️ Built With

* **HTML5**: Used for structuring the content, using semantic elements, and linking multiple pages together.

---
